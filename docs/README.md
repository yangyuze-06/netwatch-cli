# Documentation

`docs/` 按用途分组，避免历史计划和交接文档堆在同一层。

## Directories

- `handoff/`：给不同 AI agent 的交接文档，记录当前状态、边界和下一步注意事项。
- `plans/`：版本规划与历史路线，保留各个 v0.x 阶段的设计记录。
- `features/`：专项功能设计文档，例如 `speedtest.cn` browser automation。
